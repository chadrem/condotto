**Why this milestone matters (the product thesis, DESIGN §1).** The north-star is
empowering people with **domain expertise but not coding skill — product managers
first — to build features themselves** via Slack, with a software engineer (the
architect) guiding and gating in the *same thread*. For that to be real the
implementer must be a **first-class Claude Code agent**: best model, high reasoning
effort, subagents/workflows, the team's skills. M0–M3 built a safe but constrained
single-agent implementer; M3.5 exposes the real Claude Code power to the architect
as in-thread controls, still behind the §4 gate.

**State:** Milestones 0, 1, 2, 3 are DONE, plus M3.1 guided onboarding (a bare
`@Conduit` self-guides setup with a repo picker). 135 tests green, `tsc` clean,

Mode, and live: gating + defer-based approval loop, roles (architect-only), per-repo
test/land/deploy (land/deploy daemon-run through the gate, echo/no-op on testrepo),

**Verified SDK facts (DO NOT re-derive — DECISIONS.md 2026-07-18 "Milestone 3.5
planned"; re-confirm exact model IDs against live docs before building):**
- `query({ options: { model } })` accepts exact IDs: `claude-opus-4-8`,
  `claude-fable-5`, `claude-sonnet-5`.
- `options.effort ∈ {low, medium, high, xhigh, max}`, independent of extended
  thinking. `xhigh`: Fable 5 / Opus 4.8·4.7 / Sonnet 5. `max`: + Opus 4.6 / Sonnet 4.6.
- **Subagent tool calls ARE gateable** — a `PreToolUse` hook fires INSIDE subagents
  too, with `agent_id`/`agent_type` on the hook input. Enabling `Agent`/`Task` does
  NOT bypass the gate. Defense-in-depth: give a subagent a restricted `tools` list.
  **The one unverified piece → spike before Tier B:** our defer→Slack-approval→resume
  loop re-driving a *subagent-initiated* gated call is M0-proven only for the main
  agent. Run an M0-style spike (like `spikes/m0/`) first; log it in DECISIONS.md.
- **"ultracode" is CLI-only, not an SDK flag** — it is `xhigh` + standing permission
  to launch multi-agent workflows. Reproduce at the SDK with `effort:"xhigh"` + the
  `Agent`/`Workflow` tools (the `Workflow` tool exists in our SDK ≥0.3.149; we run
  0.3.214). Confirm the exact subagent tool name in-SDK (`Task` vs `Agent`).
- `settingSources:["project"]` (+ `skills:"all"` / `skills:[...]`) selectively loads
  a repo's config while the gate still applies — but it also loads that repo's
  permissions/hooks/MCP, so it is **trust-scoped** (opt-in per repo). Daemon-defined
  programmatic `agents`/`mcpServers` avoid repo trust and are preferred where they fit.

**Next work: Milestone 3.5** (DESIGN §8) — build in tiers, safest first, each tier
independently demoable:

- **Tier A — model + effort (safe, do first, no spike).** Persist `model` + `effort`
  per session (new session columns, like `budget_limit_usd`), with per-repo defaults
  (`conduit.repos.json`) + a global default (**default to Opus + `high`**). Architect
  commands `@Conduit model <opus|fable|sonnet>` / `@Conduit effort <high|xhigh|max>`;
  surface current values in the intro/status/threadCommandHelp. Wire through the
  harness port to `query()` options. **Ports:** model/effort are harness config the
  core persists and passes through (opaque strings), NEVER core policy; the adapter
  validates against `HarnessCapabilities.supportedModels/Efforts` (add these). Carry
  per-turn via `TurnInput` (like `budgetUsd`) or session create/resume opts.
- **Tier B — subagents + workflows (spike first).** Architect opt-in per session,
  default OFF: `@Conduit subagents on`, and an `@Conduit ultra on` preset (= `xhigh`
  + `Agent`+`Workflow` tools). SPIKE the subagent-initiated defer/resume path first;
  then un-disallow `Agent`/`Workflow`, give subagents restricted default toolsets,
  ensure worktree confinement + the gate cover subagent calls. Watch the M0 batching
  caveat (parallel tool calls) — the `canUseTool` deny-by-default backstop must still
  hold for batched subagent calls.
- **Tier C — skills / project config (trust-scoped).** A repo marked `trusted: true`
  in `conduit.repos.json` enables `settingSources:["project"]` + `skills` so its
  `CLAUDE.md`/skills/`.claude/agents` load; daemon-configured MCP via `mcpServers`.
  Untrusted repos unchanged. Small trust model required.
- **Dial-down:** give the architect a way to lower capability (cheaper model / lower
  effort / subagents off) — model×effort×subagents burn the subscription plan's
  **rate limit**, the real constraint (cost budgets are notional, §4).
